# DeskBasket · 桌面文件筐 ＋ 底部 Dock

Windows 桌面整理工具：把散落的文件、文件夹、快捷方式收进几个「文件夹筐」分类摆好，屏幕底部再放一条常用软件栏（Dock），Dock 上顺手带一个实时天气。桌面保持干净，东西一件不丢。

## 先说清楚：你的文件怎么被对待

- **每个筐 = 磁盘上一个真实文件夹**（默认 `E:\文件筐\<筐名>\`，设置面板可改）。加进筐的文件（或整个文件夹）会**移动**进去，从此归筐所有——原来那个位置删掉、挪走，筐里照样打得开。
- **被 Dock 或别的筐引用着的文件只复制、不移动**：搬走会把那边弄坏，所以复制一份进筐、原件留在原处。
- **程序自己绝不删除任何东西**。删除（Delete 键 / 右键「删除」）走**系统回收站**，随时可恢复——这是你亲手做的操作；「移出到桌面」是把文件搬回桌面；从清单里去掉、删除筐都只动清单，磁盘上的文件原样留着。
- **移动的跨盘场景**：先复制、逐层校验名字与大小、一致之后才删源文件；校验不过就原样保留并把原因写进日志。源文件被占用（比如正在运行的程序）也一样——副本已在筐里，原文件留着并说明。
- **落盘只有三处**：设置文件（`%APPDATA%\DeskBasket\settings.json`）、图标缓存、筐的文件夹。除此之外不写任何地方，也不上传任何数据——唯一的网络请求是天气（见下文），不发送任何本机信息。

- 环境要求：Windows 10/11 ＋ Node.js（开发态跑 Electron）
- 当前版本：3.6.0

## 它能做什么

### 文件夹筐（Dock 上的彩色文件夹图标）

点 Dock 上的筐图标弹出面板：网格图标、双击文件夹继续往里钻（同一面板内换目录）、`⌂` 回筐、`↑` 上一级、`＋` 加东西、`✕` 关闭。面板从被点的图标位置「抽」出来，右下角可拖拽调大小，调完记住。每个筐自动分配一个主色，Dock 上的文件夹图标与筐名同色。

**往筐里放东西（三个方向都是多选）**

- 把文件**拖进弹窗**：移动进筐的文件夹；
- 把文件**拖到 Dock 上那个筐图标**上：同上；
- 弹窗「＋」的文件对话框 / 设置面板的勾选清单：同上。

**把东西拿出筐**

- **从筐里拖出去**：按住格子拖到桌面或资源管理器——落点得到一份**复制**（筐里保留一份；拖拽这种交互拿不到"放哪儿了"的回执，所以做不到拖出去就消失）；
- 右键「**移出到桌面**」：真把文件搬回桌面，筐里不再保留；
- 右键「**删除**」或按 `Delete`：进**系统回收站**，可恢复。

**键鼠一览（筐弹窗里）**

| 操作 | 效果 |
|---|---|
| 单击 / Ctrl+单击 / Shift+单击 / Ctrl+A | 选中一条 / 加选 / 连选 / 全选 |
| 双击 | 文件用系统默认程序打开；文件夹进下一级 |
| `Ctrl+C` | 复制真文件进系统剪贴板（资源管理器里能直接粘贴出来） |
| `Ctrl+V` | 把剪贴板里的文件收进筐：复制来的就复制一份，剪切来的就移动 |
| `Delete` | 删除（进回收站） |
| `F2` | 重命名（改筐目录里的**真文件名**） |
| 右键 | 打开 / 在资源管理器中显示 / 复制 / 删除 / 重命名 / 移出到桌面 |

在文件管理器里删掉、挪走的文件，筐里**直接消失**（不显示灰色残影），弹窗开着时几秒内自动跟上；文件被占用、盘不在之类搬不动的情况会保留原样并在日志里说明，绝不静默丢东西。

### 底部 Dock

- **两种显示模式**：常驻显示（待在桌面层，桌面之上、所有应用窗口之下）/ 自动收起（默认：鼠标离开就滑出屏幕，碰一下屏幕底边再滑回来）。
- 里面能放四类东西：**系统图标**（开始菜单 / 此电脑 / 回收站 / 天气）、**文件夹筐**（图标下标筐名）、**快捷方式**（`.lnk` / `.url` / `.exe`）。开始菜单在最左侧，点一下弹出系统的开始菜单。
- **添加**：设置面板勾选 / 「选择文件添加…」从磁盘挑 / 直接把文件拖到 Dock 上；来源目录里新出现的快捷方式会**自动收录**（手动移除过的不会再被加回来）。
- **整理**：拖动排序；右键「打开 / 显示所在位置 / 改名… / 从 Dock 移除」。
- 图标取**不带 Windows 小箭头**的原图并自动裁掉四周空白；鼠标扫过按余弦衰减依次放大（程度可调）。

### 天气（回收站旁边那个图标）

- **图标**用 Windows 自带「天气」应用的原图（取不到时退成同款橙色方块），**图标下面一行实时写着当前气温与天气**。
- **点一下**打开系统「天气」应用（没有就退回 MSN 天气网页）。右键：「打开天气 / 刷新天气 / 换个城市… / 从 Dock 移除」。
- **鼠标靠近**浮出卡片：当前气温、体感、湿度，加未来 5 天。鼠标离开就收，不抢焦点。
- **城市**默认留空＝按网络位置自动判断；也可在设置里手填（中文名/拼音都行）。IP 定位只到城市一级。
- **数据**来自 [Open-Meteo](https://open-meteo.com/)（免费、免注册、无 API Key），每 15 分钟刷一次；取不到时保留上一次数据并注明「数据可能有点旧」。

### 收录来源目录

设置面板可以把「收录来源」指到**任意文件夹**（默认系统桌面）：把快捷方式集中搬进一个普通文件夹再指过去，桌面就既干净又看得见新下载的文件。Dock 自动收录、两份勾选清单、文件对话框默认落点都跟着走。只认绝对路径，坏路径回退系统桌面；改目录不动已收录条目。

### 外观

- **完全透明**或**磨砂玻璃**（Windows 11 系统材质）一键切换。
- **配色主题**：自动（按壁纸亮度切深/浅）/ 强制深色 / 强制浅色。
- **减弱动画**开关；Dock 图标大小、悬停放大、离屏幕底边的距离、弹窗内图标大小都可调。

### 其他

托盘常驻 · 开机自启（写 `HKCU\...\Run`，随时可取消）· 单实例保护 · **多显示器**（Dock 可放主屏、跟随鼠标或指定某块，弹窗跟着走）· 设置文件每次成功保存前留 `.bak`，主文件损坏自动从备份恢复。

## 怎么使用

```bash
npm install     # 装依赖
npm start       # 启动（进托盘，屏幕底部出现 Dock）
npm run dist    # 打包免安装 exe（产物在 dist/）
```

启动后没有主窗口，入口都在**托盘右键菜单**和**底部 Dock** 上。调试可以 `npm run dev`（带开发者工具）或 `electron . --settings`（启动直接开设置面板）。

### 常用操作

| 我想… | 怎么做 |
|---|---|
| 新建一个筐 | 托盘菜单或设置面板 →「新建文件夹」，再给它改名 |
| 往筐里放东西 | 拖进筐弹窗 / 拖到 Dock 的筐图标上 / 弹窗「＋」/ 设置面板勾选（文件会移动进筐的文件夹） |
| 打开 / 收起筐 | 点 Dock 上的筐图标；再点一次收起 |
| 把文件从筐里拿出来 | 拖到目的地（得到一份复制）；或选中后右键「移出到桌面」（真搬回去）；或 `Delete` 删除进回收站 |
| 改筐里文件的名字 | 选中按 `F2`，或右键「重命名」（改真文件名） |
| 整理快捷方式 | 设置面板 →「Dock 上的快捷方式」里勾选 |
| 让桌面彻底干净 | 快捷方式集中搬进一个文件夹，设置面板 →「收录来源目录」指过去 |
| 看天气 / 开天气应用 | 点 Dock 上那个天气图标；鼠标停上去看未来几天 |
| 改图标名字 | 右键图标 →「改名…」（Dock 图标只改显示名，不改文件名） |
| 让 Dock 别挡窗口 | 常驻显示（桌面层）或自动收起，二选一 |
| 打开开始菜单 | 点 Dock 最左边那个 Windows 图标 |

### 常见问题

- **第一次打开筐稍慢**：图标首次要从系统取，取过就缓存（`%APPDATA%\DeskBasket\icon-cache`），之后秒开。
- **改「磨砂模式」要重开弹窗才生效**：窗口材质在创建时就定了，弹窗每次打开都会按当前设置重建。
- **天气城市不对 / 显示取不到**：默认按网络位置判断，IP 只能到城市一级，可在设置里手填；连不上 Open-Meteo 时保留上次数据，网络恢复自动刷新，也可右键天气图标手动刷。
- **来源目录换了之后有些 Dock 图标失效**：Dock 上的快捷方式按路径引用文件，原路径被挪走就失效（筐里的文件不在此列：已搬进筐目录、归筐所有）。
- **为什么有的文件是"复制"进筐的**：那个文件同时还在 Dock 上用（或别的筐里），直接搬走会把那边弄坏，所以复制一份进筐、原件留在原处。
- **为什么从筐里拖出去是复制**：拖拽拿不到"放哪儿了"的回执，做不到拖出去就从筐里消失；要真正移出请右键「移出到桌面」，或在资源管理器里粘贴后用「移出到桌面」/`Delete` 清理筐里那份。
- **筐里删掉的东西还能找回吗**：`Delete`/右键删除都进系统回收站，可恢复。
- **日志里有一条 `WSALookupServiceBegin failed with: 10108`**：Electron 内置 Chromium 查系统服务失败后自行退回别的方式，与本程序无关。
- **本程序会联网吗**：只有天气这一处（Open-Meteo；城市留空时多一次 `ipwho.is` 定位）。不想要就取消勾选天气图标，程序会停掉定时请求。除此之外不发送任何东西。
- **设置存在哪**：`%APPDATA%\DeskBasket\settings.json`。删掉等于恢复出厂（桌面文件不受影响）。

## 开发

```bash
npm test        # 纯逻辑单测（node --test）
npm run dev     # 带开发者工具启动
```

架构：Electron 主进程 `src/main/`（窗口编排、托盘、IPC、Dock 位置与收放、全局鼠标状态、筐文件落地、天气服务）＋ 渲染层页面 `src/renderer/`（Dock、文件夹弹窗、设置面板、右键菜单、改名输入窗、天气卡片）。纯逻辑（配置、筐模型、筐文件命名与搬运决策、Dock 布局、天气译码与解析、图标协议）都做成不依赖 Electron 的模块，直接单测。

`scripts/desktop_snapshot.py` ＋ `scripts/desktop_compare.py` 是「程序没动过桌面」的只读取证：先拍快照，用一阵子再拍一张比对，正常结果是 `DESKTOP_UNCHANGED_OK`（快照含真实文件名，已被 `.gitignore` 排除，不要提交）。
