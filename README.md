# DeskBasket · 桌面文件筐 ＋ 底部 Dock

Windows 桌面整理工具：散落的文件、快捷方式、文件夹，**一键按类收进几个「文件夹筐」**；屏幕底部一条常用软件栏（Dock），筐图标直接长着内容缩略图；顺手带实时天气。桌面保持干净，东西一件不丢。

Electron 43 ＋ 原生 JavaScript：无前端框架，纯逻辑全部拆成不依赖 Electron 的模块直接单测。

## 先说清楚：你的文件怎么被对待

- **每个筐 = 磁盘上一个真实文件夹**（默认 `E:\文件筐\<筐名>\`，设置面板可改）。加进筐的文件（或整个文件夹）会**移动**进去，从此归筐所有——原来那个位置删掉、挪走，筐里照样打得开。
- **被 Dock 或别的筐引用着的文件只复制、不移动**：搬走会把那边弄坏，所以复制一份进筐、原件留在原处。
- **程序自己绝不删除任何东西**。删除（Delete 键 / 右键「删除」）走**系统回收站**，随时可恢复；「移出到桌面」是把文件搬回桌面；从清单里去掉、删除筐都只动清单，磁盘上的文件原样留着。
- **跨盘移动**：先复制、逐层校验名字与大小、一致之后才删源文件；校验不过就原样保留并把原因写进日志。源文件被占用（比如正在运行的程序）也一样——副本已在筐里，原文件留着并说明。
- **一键整理**执行前先预览、你确认了才动手；每一次整理都记下「从哪搬到哪」，**一键撤销**原路搬回。
- **主进程落盘只有三处**：设置文件（`%APPDATA%\DeskBasket\settings.json`）、图标缓存、筐的文件夹；此外启动器 `scripts/launch.js` 会向 `%TEMP%` 追加两份日志。除此之外不写任何地方。
- **升级不碰数据**：安装包只替换程序本体；筐登记、筐里的文件、Dock 布局全部原样保留。
- **联网只有天气一处**（Open-Meteo；城市留空时多一次 `ipwho.is` 定位），不发送任何本机信息。

## 功能总览

### 一键整理桌面

「开始」图标右键 → **一键整理桌面…**：扫描桌面 → 按扩展名分类（快捷方式 / 文档 / 图片 / 媒体 / 程序与安装包 / 其他）→ 预览窗逐类勾选（每类列出目标筐、文件清单、为什么有些文件不会动）→ 确认后按类建筐，文件搬进各自筐文件夹。规则克制：一类凑够 2 个才单独建筐、一次最多新建 4 个、已有同名筐直接复用、Dock 或别的筐引用着的文件不动、文件夹保持原位。整理完可**一键撤销**。

### 底部 Dock

- **两种显示模式**：自动收起（默认：鼠标离开就滑出屏幕，碰一下底边再滑回来）/ 常驻显示（待在桌面层）；`F9` 全局热键随时唤出/收起（`dock_hotkey` 可换，看门狗自动补注册）。
- **四类内容**：系统图标（开始菜单 / 此电脑 / 回收站 / 天气）、**文件夹筐**、快捷方式（`.lnk` / `.url` / `.exe`），外加从来源目录**自动收录**的新快捷方式（手动移除过的不再加回）。
- **筐图标自带叠放预览**：筐色底板上 2×2 摆着前 4 个条目的缩略 + 数量角标，不开弹窗就知道筐里装了什么。
- **右键菜单**：打开 / 显示所在位置 / 改名（只改显示名）/ 清理失效项 / 移除；指向已不存在文件的条目自动**灰显**并把名字上墙。
- 图标取不带 Windows 小箭头的原图、96px 高分辨率源渲染（150% 系统缩放下悬停放大依然锐利）；鼠标扫过按余弦衰减依次放大；图标下名字行带背板药丸，压得住任何壁纸。

### 文件夹筐弹窗（「宝石玻璃」）

点筐图标弹出面板：网格图标、双击进目录、`⌂` 回筐、`↑` 上一级、`＋` 添加、`✕` 关闭；右下角拖拽调大小（调完记住）。深浅配色跟壁纸自动切，完全透明 / 系统磨砂两种窗口材质可选。每个筐一个主色，Dock 图标、筐名、选中环、拖拽提示全部同色。

**键鼠一览**

| 操作 | 效果 |
|---|---|
| 单击 / Ctrl+单击 / Shift+单击 / Ctrl+A | 选中 / 加选 / 连选 / 全选 |
| 双击 | 文件用系统默认程序打开；文件夹进下一级 |
| 方向键 / Home / End | 键盘移动选中格子 |
| Enter | 打开选中条目 |
| **空格** | **预览**：图片直看、文本读前 400KB、音视频直接播；再按空格 / Esc 关闭 |
| **按住拖动** | **换位**：插入线实时跟随，松手落位（只调显示顺序，磁盘不动、重启不丢） |
| **拖出弹窗** | **移出到落点**：文件归落点、筐里不再保留（误拖可从回收站找回；松手在弹窗里＝取消） |
| 拖文件**进来** | 移动进筐 |
| `Ctrl+C` / `Ctrl+V` | 复制真文件进系统剪贴板 / 把剪贴板里的文件收进筐（复制来的复制、剪切来的移动） |
| `Delete` | 删除（进回收站） |
| `F2` | 重命名（改筐目录里的真文件名） |
| 右键 | 打开 / 在资源管理器中显示 / 复制 / 删除 / 重命名 / 移出到桌面 |

在资源管理器里删掉、挪走的文件，筐里**直接消失**（不留灰色残影），弹窗开着时几秒内自动跟上；搬不动的情况（文件被占用、盘不在）保留原样并在日志里说明，绝不静默丢东西。

### 天气

Dock 天气图标下实时写着气温与天气；点一下打开系统天气应用；鼠标停上去浮出卡片（当前气温、体感、湿度＋未来 5 天），移开约 0.2 秒收起。数据来自 [Open-Meteo](https://open-meteo.com/)（免费、免注册、无 Key），每 15 分钟刷新，断网保留旧数据并注明「数据可能有点旧」；城市默认按网络位置判断，也可在设置里手填。

### 外观与杂项

- 「宝石玻璃」设计语言：面板罩一层筐色低饱和彩调，头部宝石徽章、玻璃按钮组，图标坐在按文件类型染色的釉面底板上；深浅两套配色随壁纸自动切；完全透明 / 系统磨砂两种窗口材质可选。
- 托盘常驻 · 开机自启（随时可取消）· 单实例保护 · 多显示器（Dock 可放主屏、跟随鼠标或指定某块）· 设置文件每次保存前留 `.bak`，主文件损坏自动恢复。
- 收录来源目录可指向任意文件夹：快捷方式集中搬进一个普通文件夹再指过去，桌面既干净又看得见新文件。

## 安装

- **安装包**（推荐）：`DeskBasket-Setup-x.x.x.exe`——桌面＋开始菜单快捷方式、应用列表可见、支持卸载；装进当前用户目录不需要管理员；升级只替换程序本体，不动你的筐和文件。
- **绿色运行**：不用装，`启动DeskBasket.cmd` 双击即起（已经在跑会明说、缺依赖会指路、起不来会打出日志尾部）。

## 源码开发

环境：Windows 10/11 ＋ Node.js（mac/Linux 可跑核心功能，Windows 专属能力自动关闭）。

```bash
npm install
npm start        # 启动（进托盘，屏幕底部出现 Dock）
npm test         # 纯逻辑单测（node --test）
npm run dist     # 打 NSIS 安装包（产物在 dist/）
npm run dev      # 带开发者工具启动
```

```
src/main/        主进程：窗口编排、IPC、Dock 位置与收放、文件搬运管线、图标抽取、整理规划
src/renderer/    渲染层：dock / popup / organize / preview / settings / menu / 天气卡
tests/           纯逻辑单测（筐数据模型、搬运决策、Dock 布局、整理规划、启动器判读…）
scripts/         一键启动器、应用图标生成、桌面只读取证脚本
```

## 配置速查（`%APPDATA%\DeskBasket\settings.json`）

| 键 | 默认 | 说明 |
|---|---|---|
| `dock_auto_hide` | `true` | 鼠标离开就收起；`false` 常驻（桌面层摆放） |
| `dock_hotkey` | `"F9"` | 唤出/收起 Dock 的全局热键，`""` 关闭 |
| `shortcuts_dir` | 桌面 | Dock 收录来源目录 |
| `basket_dir` | `E:\文件筐` | 筐文件夹的根 |
| `dock_icon_size` | `48` | Dock 图标尺寸（源图 96px，放大不糊） |
| `accent_mode` | `off` | `off` 完全透明 / `acrylic` 系统磨砂 / `blur` 轻量模糊 |
| `theme_mode` | `auto` | `auto` 按壁纸亮度 / `dark` / `light` |

删掉整个 settings.json 等于恢复出厂（桌面文件不受影响）。

## 常见问题

- **第一次打开筐稍慢**：图标首次要从系统取，取过就缓存（`%APPDATA%\DeskBasket\icon-cache`），之后秒开。
- **双击启动器说「已经在运行」但看不到 Dock**：常驻模式下 Dock 待在桌面图标那一层，被别的窗口盖住时它在后面；想让它总是够得着，设置里改成「自动收起」（`Win+D` 会把程序窗口一起最小化，别用它找 Dock）。
- **改「磨砂模式」要重开弹窗才生效**：窗口材质创建时就定了，弹窗每次打开都按当前设置重建。
- **为什么有的文件是"复制"进筐的**：那个文件同时还在 Dock 上用（或别的筐里），直接搬走会把那边弄坏。
- **从筐里拖出去的东西去哪了**：拖出即移出——落点收到文件、筐里不再保留；稳妥起见原件先进回收站（可恢复），回收站清空后才彻底消失。
- **筐里删掉的东西能找回吗**：`Delete`/右键删除都进系统回收站，可恢复。
- **日志里有一条 `WSALookupServiceBegin failed with: 10108`**：Chromium 自查失败后自行回退，与本程序无关。
