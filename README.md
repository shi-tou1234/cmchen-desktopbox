# DeskBasket · 桌面文件筐 ＋ 底部 Dock

Windows 桌面整理工具：把散落的文件、文件夹、快捷方式收进几个「文件夹筐」分类摆好，屏幕底部再放一条常用软件栏（Dock）。桌面保持干净，东西一件不丢。

**它不动你的文件。** 筐和 Dock 只登记文件的绝对路径，绝不移动、删除、改名、改属性——磁盘上的文件、位置、时间戳全都保持原样。整个程序只有两处落盘：设置文件和图标缓存。「改名」也只改**显示名**（存在设置里），文件名一个字不动。

- 环境要求：Windows 10/11 ＋ Node.js（开发态跑 Electron）
- 当前版本：3.1.0

## 它能做什么

### 文件夹筐（Dock 上的彩色文件夹图标）

- 点 Dock 上的筐图标弹出面板：网格图标、**双击文件夹继续往里钻**（同一面板内换目录）、`⌂` 回筐、`↑` 上一级、`＋` 加东西、`✕` 关闭。
- **双击文件**用系统默认程序打开；右键有「打开 / 在资源管理器中显示 / 从这个筐移除」（移除只是取消登记）。
- 面板从被点的图标位置「抽」出来，鼠标离开自动收起；右下角可拖拽调大小，调完记住。

### 底部 Dock

- **只在桌面上显示**，不压在其他程序上面。两种模式：
  - **常驻显示**：待在桌面层（桌面之上、所有应用窗口之下）；
  - **自动收起**（默认）：鼠标离开就滑出屏幕，碰一下屏幕底边再滑回来。
- 里面能放：**系统图标**（此电脑 / 回收站）、**文件夹筐**（图标下标筐名）、**快捷方式**（`.lnk` / `.url` / `.exe`）。
- 添加：设置面板勾选 / 「选择文件添加…」从磁盘挑 / 直接把文件拖到 Dock 上；来源目录里新出现的快捷方式会**自动收录**（手动移除过的不会再被加回来）。
- 拖动排序；右键「打开 / 显示所在位置 / 改名… / 从 Dock 移除」。
- 图标取**不带 Windows 小箭头**的原图并自动裁掉四周空白；鼠标扫过按余弦衰减依次放大（程度可调）。

### 收录来源目录

设置面板里可以把「收录来源」指到**任意文件夹**（默认是系统桌面）：

- 想让桌面彻底干净？把快捷方式集中搬进一个普通文件夹，再把来源指过去——Dock 自动收录、设置面板两份勾选清单、文件对话框的默认落点都跟着走。
- 只认**绝对路径**；填了不存在的路径或相对路径会被回退成系统桌面。
- 改目录不会动已收录的条目（它们按路径引用文件）；来源目录里的文件再挪走或改名，对应的图标会失效，重新指认或手动清理即可。

### 外观

- **完全透明** 或 **磨砂玻璃**（Windows 11 系统材质）一键切换。
- **配色主题**：自动（按壁纸亮度在深/浅两套配色间切换）／强制深色／强制浅色。
- **减弱动画**开关（保留悬停放大，由独立百分比控制）。
- Dock 图标大小、悬停放大、离屏幕底边的距离、弹窗内图标大小都可调。
- 每个筐自动分配一个主色，Dock 上的文件夹图标与筐名同色。

### 其他

设置面板 · 托盘常驻 · 开机自启（写 `HKCU\...\CurrentVersion\Run`，随时可取消）· 单实例保护 · **多显示器**（Dock 可放主屏、跟随鼠标或指定某块，弹窗/改名窗跟着走）· 设置文件每次成功保存前留 `.bak`，主文件损坏自动从备份恢复。

## 怎么使用

### 跑起来

```bash
npm install     # 装依赖
npm start       # 启动（进托盘，屏幕底部出现 Dock）
npm run dist    # 打包免安装 exe（产物在 dist/）
```

启动后没有主窗口，入口都在**托盘右键菜单**和**底部 Dock** 上。调试可以 `npm run dev`（带开发者工具）或 `electron . --settings`（启动直接开设置面板）。

### 常用操作

| 我想… | 怎么做 |
|---|---|
| 新建一个筐 | 托盘菜单或设置面板 →「新建文件夹」，再给它改名 |
| 往筐里放东西 | 把文件拖到 Dock 上那个筐图标上（或弹窗「＋」、或设置面板勾选） |
| 打开 / 收起筐 | 点 Dock 上的筐图标；再点一次收起 |
| 从筐里拿出文件 | 弹窗里右键那条 →「从这个筐移除」（磁盘文件不动） |
| 整理快捷方式 | 设置面板 →「Dock 上的快捷方式」里勾选 |
| 让桌面彻底干净 | 快捷方式集中搬进一个文件夹，设置面板 →「收录来源目录」指过去 |
| 改图标名字 | 右键图标 →「改名…」（只改显示名，不改文件名） |
| 让 Dock 别挡窗口 | 常驻显示（桌面层）或自动收起，二选一 |

### 常见问题

- **第一次打开筐稍慢**：图标首次要从系统取，取过就缓存（`%APPDATA%\DeskBasket\icon-cache`），之后秒开。
- **改「磨砂模式」要重开弹窗才生效**：窗口材质在创建时就定了，弹窗每次打开都会按当前设置重建。
- **来源目录换了之后有些图标失效**：条目按路径引用文件，原路径的文件被挪走就会失效；在 Dock 上右键移除，或把文件放回原处。
- **日志里有一条 `WSALookupServiceBegin failed with: 10108`**：Electron 内置 Chromium 的网络模块在查系统服务，失败会自行退回别的方式，与本程序无关。
- **设置存在哪**：`%APPDATA%\DeskBasket\settings.json`。删掉等于恢复出厂（桌面文件不受影响）。

## 开发

```bash
npm test        # 纯逻辑单测（node --test）
npm run dev     # 带开发者工具启动
```

架构：Electron 主进程 `src/main/`（窗口编排、托盘、IPC、Dock 位置与收放）＋ 渲染层页面 `src/renderer/`（Dock、文件夹弹窗、设置面板、右键菜单、改名输入窗）。纯逻辑（配置、筐模型、Dock 布局、图标协议）都做成不依赖 Electron 的模块，可以直接单测。

`scripts/desktop_snapshot.py` ＋ `scripts/desktop_compare.py` 是「程序没动过桌面」的只读取证：先拍桌面快照，用一阵子再拍一张比对，正常结果是 `DESKTOP_UNCHANGED_OK`。
