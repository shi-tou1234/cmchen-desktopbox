# DeskBasket · 桌面文件筐 ＋ 底部 Dock

把桌面上散落的文件、文件夹、快捷方式收进几个「文件夹筐」里分类摆好，点一下就能打开；屏幕底部再放一条常用软件栏（Dock），随手点开常用程序。

**它不动你的文件。** 筐只登记文件的绝对路径，绝不移动、删除、改名、改属性——桌面上的图标、位置、时间戳全都保持原样，筐是一层"分类视图 + 启动面板"。Dock 上的「改名」也只改**显示名**（存在设置里），磁盘上的文件名一个字都不动。

---

## 功能

### 文件夹筐（点 Dock 上的文件夹图标弹出）

- 面板里是网格图标，**双击文件夹继续往里钻**（在同一个面板内换目录，不再另开窗口），`⌂` 回筐、`↑` 上一级、`＋` 往筐里加东西、`✕` 关闭。
- **双击文件**用系统默认程序打开；右键文件有「打开 / 在系统资源管理器中显示 / 从这个筐移除」。
- 面板从被点的那个图标位置"抽"出来，鼠标离开自动收起。

### 往筐里放东西（怎么顺手怎么来）

| 方式 | 适合 |
|---|---|
| **设置面板里勾选** | 一次归置一堆：选中筐后，下面就是桌面上所有条目的清单，勾上即加入、取消即移出 |
| **弹窗左上角「＋」** | 加不在桌面上的文件（对话框里按住 Ctrl / Shift 可多选） |
| **把文件拖进弹窗** | 拖一批进去，边框会亮一圈 |
| **把文件拖到 Dock 的文件夹图标上** | 最顺手：图标亮一圈，松手后名字那行闪一下「＋N」当回执 |

设置面板里另有「添加文件…／添加文件夹…」两个按钮，两种对话框分开（Windows 上文件与文件夹不能混在一个对话框里选）。

### 底部 Dock

- **只在桌面上显示**，不压在其他程序上面。两种模式二选一：
  - **常驻显示**：待在桌面层（桌面之上、所有应用窗口之下）；
  - **自动收起**（默认）：鼠标不在附近就滑到屏幕外，碰一下屏幕底边再滑出来。
- 里面可以放：**系统图标**（此电脑 / 回收站）、**文件夹筐**（图标下面显示筐名）、**快捷方式**。
- 添加：设置面板里勾选桌面上的条目 / 「选择文件添加…」从磁盘挑 / 直接把文件拖到 Dock 上；桌面新出现的 `.lnk` / `.url` / `.exe` 也会自动收录。
- 拖动图标可以排序；右键有「打开 / 用系统资源管理器打开所在位置 / 改名… / 从 Dock 移除」；移除过的条目不会被自动收录加回来。
- 图标取的是**不带 Windows 小箭头**的原图，并会自动裁掉四周空白（有些 `.ico` 的图案只占画布一角，原样画出来会显得"图标偏小"）。
- 鼠标扫过时按余弦衰减依次放大（放大程度可调）；按下有回弹、点开时图标向上跳一下。

### 外观

- **完全透明** 或 **磨砂玻璃**（Windows 11 系统材质），一键切换。
- **配色主题**：自动（按桌面壁纸亮度在深/浅两套配色间切换）／强制深色／强制浅色。浅色壁纸上不再出现"浅色字看不清"。
- **减弱动画**开关：关掉入场、翻页、弹跳等装饰动画（悬停放大仍由下面的百分比单独控制），照顾晕动与低配机器。
- Dock 图标大小、悬停放大程度、**离屏幕底边的距离**、文件夹弹窗内的图标大小都可以调。
- 文件夹弹窗可以**拖右下角调大小**，调完记住，下次打开就是那个尺寸。
- 每个文件夹筐自动分配一个主色，Dock 上的文件夹图标与筐名同色——并排放几个筐一眼分得清。

### 其他

设置面板（含开机自启、恢复默认）· 托盘常驻 · 单实例保护（重复启动不会出现两条 Dock）· **多显示器**（Dock 可放主屏、跟随鼠标所在屏，或指定某一块，弹窗/改名窗跟着走）· 设置文件每次成功保存前留一份 `.bak`，主文件万一损坏会自动从备份恢复。

## 怎么使用

### 跑起来

```bash
npm install     # 装依赖
npm start       # 启动（会直接进托盘，右下角出现图标）
```

打包成免安装 exe：

```bash
npm run dist    # 产物在 dist/ 目录
```

开机自启：设置面板 → 系统 → 勾上「开机自启动」（写 `HKCU\...\CurrentVersion\Run`，随时可以取消）。
启动后没有主窗口，所有入口都在**托盘右键菜单**和**屏幕底部的 Dock** 上。

### 常用操作

| 我想… | 怎么做 |
|---|---|
| 新建一个筐 | 托盘菜单或设置面板 → 新建文件夹，然后给它改名 |
| 往筐里放东西 | 把文件拖到 Dock 上那个文件夹图标上（或弹窗「＋」、或设置面板里勾选） |
| 打开筐 | 点 Dock 上的文件夹图标；再点一次收起 |
| 从筐里拿出某个文件 | 弹窗里右键那条 →「从这个筐移除」（只是取消登记，磁盘文件不动） |
| 整理桌面上的快捷方式 | 设置面板 →「Dock 上的快捷方式」里勾选 |
| 给 Dock 上的图标改个名字 | 右键图标 →「改名…」（只改显示名），或设置面板里那一行的「改名」 |
| 让 Dock 别挡着窗口 | 设置面板 → 勾上「常驻显示」＝待在桌面层；或关掉它＝鼠标离开自动收起 |
| 让 Dock 抬高一点 | 设置面板 →「离屏幕底边的距离（px）」 |

### 常见问题

- **第一次打开某个筐稍慢**：图标第一次要从系统里取，取过的会缓存（缓存放在 `%APPDATA%\DeskBasket\icon-cache`），之后就是秒开。
- **改了「磨砂模式」要重新打开弹窗才生效**：窗口材质在创建时就定下来了，弹窗每次打开都会按当前设置重建。
- **日志里有一条 `WSALookupServiceBegin failed with: 10108`**：这是 Electron 内置 Chromium 的网络模块在查询系统服务，失败会自己退回别的通知方式，与本程序无关，可以忽略。
- **设置存在哪**：`%APPDATA%\DeskBasket\settings.json`。删掉它就等于恢复出厂设置（桌面文件不受影响）。

## 开发

```bash
npm test        # 纯逻辑单测（node --test，92 条）
npm run dev     # 带开发者工具启动
```

架构：Electron 主进程 `src/main/`（窗口编排、托盘、IPC、Dock 位置与收放）+ 渲染层页面 `src/renderer/`（Dock、文件夹弹窗、设置面板、右键菜单、改名输入窗）。纯逻辑（配置、筐模型、Dock 布局、图标协议）都在 `src/main/*.js` 里做成不依赖 Electron 的模块，可以直接单测。

`scripts/desktop_snapshot.py` + `scripts/desktop_compare.py` 是"程序没动过桌面"的只读取证：先拍一张桌面快照，用一阵子再拍一张比对，正常结果是 `DESKTOP_UNCHANGED_OK`。
