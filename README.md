# DeskBasket · 桌面文件筐 ＋ 底部 Dock

Windows 桌面整理工具：把散落的文件、文件夹、快捷方式收进几个「文件夹筐」分类摆好，屏幕底部再放一条常用软件栏（Dock），Dock 上顺手带一个实时天气。桌面保持干净，东西一件不丢。

**文件会移动进筐，但程序从不删除任何文件。** 每个筐在磁盘上有一个自己的真实文件夹（默认 `E:\文件筐\<筐名>\`），加进筐的文件（或整个文件夹）会**移动**进去，从此归筐所有 —— 原来那个位置删掉、挪走，筐里照样打得开。Dock 也在用的快捷方式**只复制一份**进筐，原件留在原处，免得 Dock 上那条变失效。程序不做删除：从筐里移出、删除筐都只动清单，磁盘上的文件原样留着；唯一会碰到"源文件"的动作就是上面那次移动，而且跨盘移动是**先复制、校验一致之后才删源文件**，校验不过就原样保留并把原因写进日志。「改名」只改**显示名**（存在设置里），文件名一个字不动。落盘只有三处：设置文件、图标缓存、筐的文件夹。

- 环境要求：Windows 10/11 ＋ Node.js（开发态跑 Electron）
- 当前版本：3.3.0

## 它能做什么

### 文件夹筐（Dock 上的彩色文件夹图标）

- 点 Dock 上的筐图标弹出面板：网格图标、**双击文件夹继续往里钻**（同一面板内换目录）、`⌂` 回筐、`↑` 上一级、`＋` 加东西、`✕` 关闭。
- **双击文件**用系统默认程序打开；右键有「打开 / 在资源管理器中显示 / 从这个筐移除」（移除只是取消登记）。
- 面板从被点的图标位置「抽」出来，鼠标离开自动收起；右下角可拖拽调大小，调完记住。**拖文件进来时不会收**：去桌面或资源管理器抓文件的路上、以及整个拖拽过程中，面板都留在原地当落点。
- 每个筐自动分配一个主色，Dock 上的文件夹图标与筐名同色。
- **筐的文件在哪**：`E:\文件筐\<筐名>\`（设置面板 →「筐的文件目录」可改，只影响之后新建的筐）。加进来的文件会移动到这里，所以原位置删掉也不影响筐里能打开它；文件被占用、盘不在之类搬不动的情况，会保留原路径登记并在日志里说明。

### 底部 Dock

- **只在桌面上显示**，不压在其他程序上面。两种模式：
  - **常驻显示**：待在桌面层（桌面之上、所有应用窗口之下）；
  - **自动收起**（默认）：鼠标离开就滑出屏幕，碰一下屏幕底边再滑回来。
- 里面能放三类东西：**系统图标**（此电脑 / 回收站 / 天气）、**文件夹筐**（图标下标筐名）、**快捷方式**（`.lnk` / `.url` / `.exe`）。
- **添加**：设置面板勾选 / 「选择文件添加…」从磁盘挑 / 直接把文件拖到 Dock 上；来源目录里新出现的快捷方式会**自动收录**（手动移除过的不会再被加回来）。
- **整理**：拖动排序；右键「打开 / 显示所在位置 / 改名… / 从 Dock 移除」。
- 图标取**不带 Windows 小箭头**的原图并自动裁掉四周空白；鼠标扫过按余弦衰减依次放大（程度可调）。

### 天气（回收站旁边那个图标）

- **图标**用的是 Windows 自带「天气」应用的原图（取不到时退成一个同款橙色方块），**图标下面一行实时写着当前气温与天气**，例如 `28° 阴`。
- **点一下**打开系统的「天气」应用；系统里没有这个应用（被卸载或精简系统）时退回 MSN 天气网页。右键有「打开天气 / 刷新天气 / 换个城市… / 从 Dock 移除」。
- **鼠标靠近**，在图标上方浮出一张卡片：当前气温、体感、湿度，加未来 5 天（今天/明天/后天/周几 ＋ 天气 ＋ 最高最低温）。鼠标离开就收，不抢焦点、不挡操作。
- **城市**默认留空 ＝ 按网络位置自动判断；在设置面板里填了城市就按填的取，中文名或拼音都行。IP 定位只精确到城市一级，想更准就手填。
- **数据**来自 [Open-Meteo](https://open-meteo.com/)（免费、免注册、不需要 API Key），每 15 分钟刷一次。取不到时保留上一次的数据并注明「数据可能有点旧」，不弹窗、不打断。

### 收录来源目录

设置面板里可以把「收录来源」指到**任意文件夹**（默认是系统桌面）：

- 想让桌面彻底干净？把快捷方式集中搬进一个普通文件夹，再把来源指过去——Dock 自动收录、设置面板两份勾选清单、文件对话框的默认落点都跟着走。
- 只认**绝对路径**；填了不存在的路径或相对路径会被回退成系统桌面。
- 改目录不会动已收录的条目（它们按路径引用文件）；来源目录里的文件再挪走或改名，对应的图标会失效，重新指认或手动清理即可。

### 外观

- **完全透明** 或 **磨砂玻璃**（Windows 11 系统材质）一键切换。
- **配色主题**：自动（按壁纸亮度在深/浅两套配色间切换）／强制深色／强制浅色。
- **减弱动画**开关（保留悬停放大，由独立百分比控制）。
- Dock 图标大小、悬停放大、离屏幕底边的距离、弹窗内图标大小都可调。

### 其他

设置面板 · 托盘常驻 · 开机自启（写 `HKCU\...\CurrentVersion\Run`，随时可取消）· 单实例保护 · **多显示器**（Dock 可放主屏、跟随鼠标或指定某块，弹窗/改名窗跟着走）· 设置文件每次成功保存前留 `.bak`，主文件损坏自动从备份恢复。

## 怎么使用

### 跑起来

```bash
npm install     # 装依赖
npm start       # 启动（进托盘，屏幕底部出现 Dock）
npm run dist    # 打包免安装 exe（产物在 dist/）
```

启动后没有主窗口，入口都在**托盘右键菜单**和**底部 Dock** 上。调试可以 `npm run dev`（带开发者工具）或 `electron . --settings`（启动直接开设置面板）。

### 常用操作

| 我想… | 怎么做 |
|---|---|
| 新建一个筐 | 托盘菜单或设置面板 →「新建文件夹」，再给它改名 |
| 往筐里放东西 | 把文件直接拖进筐弹窗（或拖到 Dock 上那个筐图标上、或弹窗「＋」、或设置面板勾选）；文件会移动进筐的文件夹 |
| 打开 / 收起筐 | 点 Dock 上的筐图标；再点一次收起 |
| 从筐里拿出文件 | 弹窗里右键那条 →「从筐里移出」（只取消登记，文件留在筐的文件夹里，不删） |
| 整理快捷方式 | 设置面板 →「Dock 上的快捷方式」里勾选 |
| 让桌面彻底干净 | 快捷方式集中搬进一个文件夹，设置面板 →「收录来源目录」指过去 |
| 看天气 / 开天气应用 | 点 Dock 上那个天气图标；鼠标停上去看未来几天 |
| 天气城市不对 | 设置面板 →「天气」→ 城市（留空 ＝ 按网络位置自动判断） |
| 改图标名字 | 右键图标 →「改名…」（只改显示名，不改文件名） |
| 让 Dock 别挡窗口 | 常驻显示（桌面层）或自动收起，二选一 |

### 常见问题

- **第一次打开筐稍慢**：图标首次要从系统取，取过就缓存（`%APPDATA%\DeskBasket\icon-cache`），之后秒开。
- **改「磨砂模式」要重开弹窗才生效**：窗口材质在创建时就定了，弹窗每次打开都会按当前设置重建。
- **天气显示的城市跟我不在一个市**：默认按网络位置判断，IP 只能到城市一级；在设置面板 →「天气」里填自己的城市即可。
- **天气一栏显示「取不到」**：机器连不上 Open-Meteo（断网或被代理拦），程序会保留上一次的数据继续显示；网络恢复后自动刷新，也可以右键天气图标手动刷。
- **来源目录换了之后有些图标失效**：Dock 上的快捷方式按路径引用文件，原路径的文件被挪走就会失效（筐里的文件不在此列：它们已经搬进筐目录、归筐所有）；在 Dock 上右键移除，或把文件放回原处。
- **筐里的文件到底在哪、会不会丢**：每个筐一个文件夹（默认 `E:\文件筐\<筐名>\`），筐里看到的就是那个文件夹里的东西。程序不删除文件，误从筐里移出也只是取消登记，去那个文件夹里拿就行。
- **为什么有的文件是"复制"进筐的**：那个文件同时还在 Dock 上用（或别的筐里），直接搬走会把那边弄坏，所以复制一份进筐、原件留在原处。
- **日志里有一条 `WSALookupServiceBegin failed with: 10108`**：Electron 内置 Chromium 的网络模块在查系统服务，失败会自行退回别的方式，与本程序无关。
- **本程序会联网吗**：只有天气这一处（Open-Meteo 取天气；城市留空时多一次 `ipwho.is` 定位）。不想要就把设置面板里「天气」的勾去掉，程序会停掉定时请求。除此之外不发送任何东西。
- **设置存在哪**：`%APPDATA%\DeskBasket\settings.json`。删掉等于恢复出厂（桌面文件不受影响）。

## 开发

```bash
npm test        # 纯逻辑单测（node --test）
npm run dev     # 带开发者工具启动
```

架构：Electron 主进程 `src/main/`（窗口编排、托盘、IPC、Dock 位置与收放、天气服务）＋ 渲染层页面 `src/renderer/`（Dock、文件夹弹窗、设置面板、右键菜单、改名输入窗、天气卡片）。纯逻辑（配置、筐模型、Dock 布局、天气译码与解析、图标协议）都做成不依赖 Electron 的模块，可以直接单测。

`scripts/desktop_snapshot.py` ＋ `scripts/desktop_compare.py` 是「程序没动过桌面」的只读取证：先拍桌面快照，用一阵子再拍一张比对，正常结果是 `DESKTOP_UNCHANGED_OK`。
